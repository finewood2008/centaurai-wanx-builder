# WANX 服务端接入

Builder 使用 WANX 原生应用中心、私人用户实例、Ask/Plan/Craft、连接器及技能 API，不创建另一套运行服务。

`0.5.0-standard-apps.patch` 是标准应用扩展的增量补丁，基于已经接入 Builder v2 和应用中心生命周期协议的 WANX 1.0.2b6。它包括八类任务 UI 契约、原生专家模板继承、技能包工作区接入和试用证据核验，不包含数据库迁移或用户运行数据。

补丁是集成参考，不能直接套用到任意 WANX 版本。先在隔离副本核对基础接口和上下文，再进行目标服务的部署与验收。仓库中的 `docs/builder-manifest.json` 记录构建专家的配置。
